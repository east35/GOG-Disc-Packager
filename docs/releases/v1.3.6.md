## What's new

- Corrected DVD-5 and DVD-9 planning to use their actual writable capacities instead of rounded marketing values.
- Reduced the DVD safety reserve to 96 MiB, preserving room for the launcher and filesystem overhead without rejecting packages already proven to fit on dual-layer media.
- Added a live 505 × 312 launcher-background preview to the packager.
- Added a horizontal focus slider so wide SteamGridDB-style artwork can be positioned before building the package.
- Saved the chosen background position in package metadata so the generated launcher reproduces the previewed crop.

This release resolves GitHub issues #6 and #7.

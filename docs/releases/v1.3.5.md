## What’s new

- Fixed **Use my disc inventory** for multi-game, single-disc collections. The packager now automatically selects the smallest available blank with enough usable capacity and offers to deduct it after a successful build.
- Made collection install detection game-specific by combining the collection title, individual game or edition title, and installer identity. This prevents generic labels such as “Enhanced Edition” from matching an unrelated installed game.
- Added validation for saved install targets so stale or mismatched launcher state is ignored.
- Moved **Keep launcher open** into the launcher’s overflow menu, reducing its visual priority while preserving the remembered preference.
- Improved collection navigation by placing Back before the overflow button while viewing an individual game.
- Added polished default cover art, background art, and game icon for packages built without custom assets. The default icon is also used for the generated disc icon and AutoRun metadata.

This patch rolls up the collection-disc and launcher presentation fixes validated after v1.3.4.

## What’s new

- Added a **Keep launcher open** toggle to the launcher’s install, installed-game, and collection screens.
- By default, the launcher now minimizes while the original GOG installer is running and returns when setup finishes.
- By default, the launcher now closes after successfully starting an installed game.
- The toggle keeps the launcher visible during both setup and gameplay when preferred, and the choice is remembered across future launches and discs.

This release addresses the launcher-window feedback in [issue #4](https://github.com/east35/GOG-Disc-Packager/issues/4).

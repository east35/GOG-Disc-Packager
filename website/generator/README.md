# Generator interface

The GOG Preservation Program toggle adds the supplied program badge above the spine game ID and to the front cover. Horizontal, vertical, and size controls position the front badge within the cover safe area. The toggle and placement persist in JSON and appear in PDF export; this is a manual designation, not an automatic eligibility lookup.

Open `/generator/` using the website's existing `npm run dev` command. The Vite build includes both the landing page and generator.

This is an interface and live layout prototype for `docs/TEMPLATE-GENERATOR-SCHEMA.md`, independent of disc packaging. It supports game metadata, case/media choices, per-disc titles and purposes, cover artwork uploads, transparent PNG game logos, focal points, artwork approval, ratings, features, requirements, and archive data. Front, back, full-wrap, game-logo, and disc artwork have position and size controls. A game logo is reused on the disc labels and can be rotated onto the spine; the spine may instead use title text. The back uses a fixed editorial blueprint—hook, synopsis, four highlight lines, and an optional screenshot strip—so users provide content without having to solve typography or placement. Blank highlight lines fall back to selected game features. Back legal copy and its warning/media marks follow the fixed Figma treatment. JSON save/open embeds uploaded artwork; nothing is uploaded to a server. Unsaved edits last only for the current page session.

The renderer uses the imported Figma coordinate geometry: 366 × 456-unit panels and a 40/50-unit spine. PDF export currently maps cover units to 0.35 mm (128.1 × 159.6 mm panels and 14/17.5 mm spines); these provisional dimensions still need physical calibration. Disc pages are 120 mm square with a 15 mm spindle opening. The renderer supports separate front, back, full-wrap, interior, disc, logo, and screenshot assets. Remote or cached asset references require re-uploading artwork for this local preview.

Save JSON keeps editable work in progress with embedded artwork; upload it with Open JSON to resume. Export PDF downloads the outside cover, case interior, and one page per disc, without preview guides. Pages contain high-resolution raster artwork (about 300 DPI); the export does not upscale source asset detail. Always print at actual size and verify a paper proof. Production bleed, crop marks, and calibrated print geometry remain future work. Drafts may be exported with validation warnings. The interactive preview caps projects at 99 discs.

Clear-case interiors support custom artwork with crop/zoom controls or the supplied generic license/safety insert, fitted to the full sheet without cropping its margins. Spines offer black or white backgrounds with contrasting title text. Disc media marks use transparent black/white PNG assets, and disc legal copy uses black text with a white outline. The front disc-count badge uses the supplied transparent gradient-bordered PNG, with dynamic text for counts other than two.

The accepted [architecture decision](../../docs/TEMPLATE-GENERATOR-ARCHITECTURE.md) targets GitHub Pages and external SteamGridDB gallery links followed by local artwork upload. Hosting migration, the gallery-link control, and source-page fields remain to be implemented. A server-side SteamGridDB integration is intentionally outside scope.

Validation: `node --test generator/*.test.js` and `npm run build`. Browser checks cover JSON import, PDF export, interior upload, black/white options, and numbered disc previews. PDF checks verify page count, physical page sizes, cross-reference offsets, and rendered output.
